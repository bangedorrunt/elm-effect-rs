# Port the cli fish completion generator rows and the shell dispatcher

Source rows: `packages/effect/test/cli/completions/completions.test.ts`, Fish
section (`:552`-`:772`, 23 rows) and the `Completions` dispatch section
(`:790`-`:802`, 3 rows).

The port adds `pub mod fish` plus a `Shell` enum and `generate` dispatch to
`crates/elm-effect-unstable/src/cli_completions.rs`.

## Witness

`crates/elm-effect-unstable/tests/cli_completions_fish.rs` — one test per fish
row, plus a byte-equality test against goldens generated by the pin's own
`fish.ts` (committed under `tests/fixtures/completions/fish/`).
`crates/elm-effect-unstable/tests/cli_completions_dispatch.rs` — the 3 dispatch
rows.

## Scope boundary

The `ComprehensiveCli` integration rows (`:814` bash, `:854` zsh, `:885` fish)
stay unported: they need the 439-line fixture transcribed, which the pin cannot
run standalone here (no built `effect` package).

## Why no modules.toml change

`completions.test.ts` is linked to no module in `conformance/modules.toml`, so
flipping these rows moves no module status. Nothing to lease.
