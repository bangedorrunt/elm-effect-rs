# A strict hand codec beats a blocked dependency

## Solution
With the manifest held, a ~120-line strict JSON codec (no trailing
commas, real escapes, own-properties-only objects) covers every
envelope row and proves itself through round-trip tests. Trailing
commas must fail at close time, not loop back for another value.

## Principles
prove-it-works — every flipped row names a test.
foundational-thinking — hand codec keeps zero deps.
