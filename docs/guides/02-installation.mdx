# Installation

The facade crate is `elm-effect`. Edition 2024.

Add a path dependency until the crate is on crates.io.

```toml
[dependencies]
elm-effect = { path = "../elm-effect-rs/crates/elm-effect" }
```

## Features

The default feature set is `tokio` alone (ADR-0003). A plain dependency gives you `Runtime`, fibers, `Scope`, `Layer`, and the remote policy.

| Feature | You get |
| --- | --- |
| `tokio` (default) | `Runtime`, fibers, `Scope`, `Layer`, remote policy |

`Runtime` needs the `tokio` feature.
