# Installation

The facade crate is `elm-effect`. Edition 2024.

Add a path dependency until the crate is on crates.io.

```toml
[dependencies]
elm-effect = { path = "../elm-effect-rs/crates/elm-effect" }
```

## Features

The default feature set is `tokio` alone (ADR-0003). A plain dependency gives you `Runtime`, fibers, `Scope`, `Layer`, and the remote policy. Code that names `Schema` or the STM cells must enable those features in your own manifest; they are not on by default.

| Feature | You get |
| --- | --- |
| `tokio` (default) | `Runtime`, fibers, `Scope`, `Layer`, remote policy |
| `schema` | `Schema` from `elm-effect-schema` |
| `stm` | `TxRef` and `atomically` |
| `full` | `schema` and `stm` together |

`Runtime` needs the `tokio` feature. Enable `full` when you call both, or name `schema` or `stm` alone.

## Related crates

| Crate | Use it for |
| --- | --- |
| `elm-effect-test` | A deterministic executor |
| `elm-effect-elm` | `Program` |
| `elm-effect-journal` | `DurableLog` and the journal plans |
| `elm-effect-unstable` | HTTP, SQL, workflow, and other unstable modules |

Do not enable `elm-effect-unstable` in a stable CLI.
