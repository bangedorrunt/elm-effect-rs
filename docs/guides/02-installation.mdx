# Installation

The facade crate is `elm-effect`. Edition 2024.

Add a path dependency until the crate is on crates.io.

```toml
[dependencies]
elm-effect = { path = "../elm-effect-rs/crates/elm-effect" }
```

## Features

There are none. `elm-effect` always depends on Tokio, because the fiber
runtime is the carrier: `Runtime`, fibers, `Scope`, `Layer`, and the remote
policy are not optional. An earlier `tokio` feature was removed in 0.4.0: it
gated those modules but not their references, so `default-features = false`
never compiled. A switch that only ever produced a compile error is worse than
no switch.
