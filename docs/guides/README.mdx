# elm-effect guides

These guides tell a Rust programmer and an agent how to use `elm-effect`.

Read the guides in order. Each guide shows how you call the API. [Use the APIs](15-use-the-apis.mdx) is the catalog. You return to it when you write code.

Extension is one chapter, [Add a capability](13-add-a-capability.mdx). ADR-0002 is the law. ADR-0003 is the adoption rule. You do not need those records for the first program.

The text uses simplified technical English. The files are MDX. The mark on a figure moves along the arrows.

## One rule

Return `Effect` from work that can fail, wait, or need a service. Keep a pure decision as a function. Call `Runtime::run` once, in `main` or in a test.
